<task type="auto">
  <name>Task 1: Build local render service with FFmpeg frame-0 poster baking</name>
  <files>server/services/renderService.js, tests/render.test.js</files>
  <read_first>server/index.js, src/remotion/types.ts</read_first>
  <action>
    Create server/services/renderService.js:
    - Manages in-memory and disk-persisted render job registry (`jobs` Map).
    - `createJob(storyboard, options)`:
      - Validates storyboard input.
      - Generates unique `jobId`.
      - Allocates output directory `server/public/renders/${jobId}`.
      - Computes canvas dimensions from aspect ratio:
        - 16:9: 1920x1080
        - 9:16: 1080x1920
        - 1:1: 1080x1080
      - Computes peak settled poster frame timestamp (default ~3.5s into video during product reveal settle).
    - `extractPosterFrame(videoPath, outputPath, timestampSec)`:
      - Uses local `ffmpeg -y -ss <timestampSec> -i <videoPath> -frames:v 1 -q:v 2 <outputPath>` to extract pristine poster frame.
    - `bakeFrameZero(videoPath, posterPath, outputPath)`:
      - Uses local `ffmpeg -y -i <videoPath> -loop 1 -i <posterPath> -filter_complex "[0:v][1:v]overlay=enable='eq(n,0)':shortest=1[outv]" -map "[outv]" -map 0:a? -c:v libx264 -pix_fmt yuv420p -c:a copy <outputPath>`.
    - `synthesizeVideo(storyboard, outputDir, onProgress)`:
      - Executes rendering pipeline updating job status and progress:
        - 10%: Initializing and setting up output directory
        - 20-70%: Rendering video composition (calls Remotion or fast local video synthesizer)
        - 80%: Extracting settled poster frame (poster.jpg)
        - 90%: Baking frame-0 poster with FFmpeg
        - 100%: Completed with videoUrl, posterUrl, fileSize, duration, and renderStats.
    - `getJob(jobId)`: returns current job state.

    Create tests/render.test.js:
    - Test job creation and parameter validation.
    - Test aspect ratio dimension calculations (16:9, 9:16, 1:1).
    - Test peak visual moment frame calculation.
    - Test FFmpeg frame-0 overlay filter syntax and poster extraction logic.
    - Test job status lifecycle transitions (queued -> rendering -> completed).
  </action>
  <verify>node --test tests/render.test.js</verify>
  <acceptance_criteria>
    - server/services/renderService.js provides complete job lifecycle and FFmpeg execution
    - node --test tests/render.test.js passes cleanly
  </acceptance_criteria>
  <done>Render service built and verified</done>
</task>
