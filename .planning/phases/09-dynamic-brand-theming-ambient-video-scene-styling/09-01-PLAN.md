# Plan 09-01: Dynamic Brand Theming & Ambient Video Scene Styling

## Objective
Eliminate the static `#070a13` navy blue background and hardcoded scene accent colors. Dynamically compute deep brand-tinted background colors and multi-stop ambient mesh glows from the company's extracted palette, propagate brand styling across all 4 scenes, and provide live Brand Color Palette controls in the Web GUI.

## Tasks
1. **Palette Extractor Overhaul (`server/services/paletteExtractor.js`)**:
   - Compute deep brand-tinted dark background color based on the extracted primary hue (e.g., HSL saturation 25%, lightness 5-7%) rather than static navy `#080c16`.
   - Compute matching surface background with brand tint.
2. **Remotion Scenes Styling Overhaul (`src/remotion/scenes/`)**:
   - Update `HookScene.tsx` to dynamically use brand `primary`, `accent`, and `background`.
   - Update `ProductRevealScene.tsx` to use full brand mesh lighting and tint.
   - Update `HighlightScene.tsx` to replace hardcoded cyan/indigo with `palette.primary` and `palette.secondary`.
   - Update `OutroScene.tsx` to replace hardcoded green with `palette.primary` and `palette.accent` for CTA button and punchline glow.
3. **Web GUI Brand Palette Editor (`src/components/StoryboardInspector.tsx`, `src/types/index.ts`)**:
   - Add interactive color pickers for Primary, Secondary, Accent, Background, and Surface in the Storyboard Inspector.
   - Allow user to tweak company colors and see instant live updates in Remotion Player.
4. **Verification**:
   - Run tests (`npm test` / Node test runner) and Vite build check.
