<objective>
Build the multimodal style transfer and prompt-driven feature synthesizer engine. Extract color palettes and design tokens from uploaded screenshots (via multimodal AI vision with deterministic local buffer fallback), and synthesize custom UI screens for whatever specific page/feature was described in the prompt themed to match the brand.

Purpose: Allow founders and marketers to showcase specific custom features described in their prompt while automatically inheriting the visual aesthetic of their uploaded brand screenshots.
Output: Palette extraction service, feature screen synthesizer component, storyboard schema updates, StoryboardInspector palette controls, and automated tests.
</objective>
