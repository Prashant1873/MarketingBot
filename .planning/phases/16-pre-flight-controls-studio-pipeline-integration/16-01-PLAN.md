# Phase 16 Plan: Pre-Flight Controls & Studio Pipeline Integration

## Objective
Integrate subtitle configuration into `PreFlightStudioPanel`, `StoryboardInspector`, `VideoPlayerPreview`, and the headless Remotion MP4 render pipeline, ensuring users can configure subtitle styling pre-flight and see them burned cleanly into the final MP4.

## Requirements Addressed
- **CAPTION-03**: Pre-flight studio controls, live player preview, safe-area layout adaptation (16:9, 9:16, 1:1), and headless MP4 caption burn-in.

## Vertical Slice Tasks

- Verify full test suite and production build (`tsc && vite build`).

- [ ] Users can toggle and pick subtitle styles in PreFlightStudioPanel before generation.
