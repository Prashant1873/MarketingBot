# Phase 15 Plan: Subtitle Timing Engine & Kinetic Caption Remotion Renderer

## Objective
Build the word-level timestamp interpolation engine and spring-animated `KineticCaptions` Remotion overlay component supporting 4 distinct visual aesthetics (`karaoke-bounce`, `clean-pill`, `cyber-glow`, `minimal`) with aspect ratio safe zones.

## Requirements Addressed
- **CAPTION-01**: Subtitle timing engine & word-by-word timestamp interpolation mapping spoken voiceover script to precise video frame windows.
- **CAPTION-02**: Multi-style animated kinetic caption Remotion renderer supporting 4 visual aesthetics (`karaoke-bounce`, `clean-pill`, `cyber-glow`, `minimal`) with spring dynamics.

## Vertical Slice Tasks

### Task 1: Word Timing & Timestamp Alignment Engine
- Create `src/utils/subtitleTiming.ts` (and server helper `server/services/subtitleTiming.js`):
  - Function `computeSceneWordTimestamps`:
    - Breaks narration script into phrases and words.
    - Factors in punctuation pauses (periods, commas, dashes, exclamation marks).
    - Allocates proportional frame durations based on character length/syllables across the scene duration.
    - Returns structured words array: `{ word: string, startFrame: number, endFrame: number, isPunctuationBreak: boolean }`.
  - Comprehensive unit tests covering empty strings, multi-sentence scripts, timing bounds, and punctuation.

### Task 2: Remotion `KineticCaptions.tsx` Component
- Build `src/remotion/captions/KineticCaptions.tsx`:
  - Consumes active `frame`, `fps` (30), `themePalette`, `style` (`karaoke-bounce` | `clean-pill` | `cyber-glow` | `minimal`), `position` (`bottom` | `middle`), and words timing array.
  - Spring-animated active word pop using `@remotion/core` spring physics (`damping: 12, stiffness: 200`).
  - Implements 4 visual styles:
    1. `karaoke-bounce`: Active word scales 1.2x with spring pop, glowing brand accent color, high-contrast dark drop-shadow.
    2. `clean-pill`: Frosted dark glass container (`rgba(0,0,0,0.7)`, backdrop blur, rounded-full) with smooth text highlight.
    3. `cyber-glow`: Neon text-shadow glow with neon brand primary/accent border.
    4. `minimal`: Understated, ultra-clean font with subtle brand color highlight on active word.
  - Safe-area positioning respecting 16:9 (lower third), 9:16 (elevated above TikTok UI bottom zone), and 1:1.

### Task 3: Remotion Composition Integration & Automated Tests
- Wire `KineticCaptions` into `src/remotion/MarcutieComposition.tsx` as an overlay across scenes.
- Add test suite `tests/captions.test.js` validating word timing calculation, boundary constraints, and style fallbacks.

## Success Criteria
- [ ] Word timing engine assigns accurate, non-overlapping frame windows to words within scene duration.
- [ ] `KineticCaptions` renders active word highlights with spring animations across all 4 styles.
- [ ] Safe-area containers avoid clipping in 16:9, 9:16, and 1:1.
- [ ] Automated tests pass (`npm test`).
