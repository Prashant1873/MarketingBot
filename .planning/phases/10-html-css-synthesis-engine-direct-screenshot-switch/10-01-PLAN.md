# Plan 10-01: HTML/CSS Synthesis Engine & Direct Screenshot Switch

## Objective
Add a user-controllable switch between 'Synthesized HTML/CSS' and 'Direct Screenshot' (defaulting to Synthesized HTML/CSS with brand style transfer), provide an interactive HTML/CSS code viewer & editor in the Storyboard Inspector, and ensure seamless switching in Remotion preview and video rendering.

## Tasks
1. **Screen Render Mode State & Switch**:
   - Add prominent switch in `ImageDropzone.tsx` and `StoryboardInspector.tsx` between `Synthesized HTML/CSS` and `Direct Screenshot`.
   - Update default behavior in `server/routes/storyboard.js` and `MarcutieComposition.tsx` so `screenMode` defaults to `"mockup"` (Synthesized HTML/CSS) rather than forcing raw screenshot.
2. **HTML/CSS Markup & Style Generator (`src/utils/htmlCssGenerator.ts`)**:
   - Create generator converting the active `featureMockup` and `themePalette` into clean, production-grade standalone HTML and CSS files with `:root` CSS variables.
3. **Interactive Code Viewer Tab in Storyboard Inspector (`src/components/StoryboardInspector.tsx`)**:
   - Add an `HTML/CSS Code` inspector tab showing the live HTML and CSS code with one-click copying and code preview.
4. **Remotion Composition Wiring (`src/remotion/scenes/ProductRevealScene.tsx`)**:
   - Honor the `screenMode` switch dynamically so users can switch between Synthesized HTML/CSS and Direct Screenshot in real time.
5. **Verification**:
   - Validate switch toggling, HTML/CSS generation, and Remotion rendering.
