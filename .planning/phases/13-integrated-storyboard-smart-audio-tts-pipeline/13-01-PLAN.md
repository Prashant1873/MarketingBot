# Phase 13 Plan: Integrated Storyboard, Smart Audio Decision & Automated TTS Pipeline

## Objective
Build the automated post-prompt decision engine that analyzes the prompt, dynamically selects the tone-matched voice model and upbeat track (when set to Auto), generates the narration script, synthesizes Kokoro-82M TTS upfront, and auto-syncs scene hold durations before video rendering.

## Requirements Addressed
- **AUTO-01**: Automated post-prompt audio & voiceover decision engine selecting tone-matched voice model and upbeat track, generating narration, synthesizing Kokoro-82M TTS, and auto-syncing scene hold durations.

## Vertical Slice Tasks

### Task 1: Smart Audio & Voice Decision Engine
- In `server/services/storyboardService.js` (and audio catalog):
  - Add `decideOptimalAudioDirection(prompt, tone)` mapping prompt keywords and tone to Ende.app Happy Beats tracks when track is `"auto"`.
  - Add `decideOptimalVoiceModel(prompt, tone)` mapping tone to Kokoro-82M voice presets (`af_heart`, `am_adam`, `af_nova`, `am_echo`) when voice is `"auto"`.

### Task 2: Upfront Kokoro TTS Synthesis & Duration Auto-Sync
- Enhance storyboard generation pipeline (`server/routes/storyboard.js`):
  - When `voiceConfig.enabled !== false`, generate complete scene narration script during AI storyboard generation.
  - Automatically call `generateVoiceover()` locally with selected/auto-decided voice.
  - Extract synthesized WAV duration and calculate exact scene frame hold extensions so speech is never rushed or clipped.
  - Attach `voiceoverTrack` (`{ url, duration, voice, duckingVolume: 0.25 }`) directly into `storyboard.audio`.

### Task 3: Automated Tests & Validation
- Write integration tests in `tests/autoAudioPipeline.test.js`:
  - Test auto music decision for varied tones (polished, parody, chaotic).
  - Test auto voice selection for varied tones.
  - Test storyboard generation with upfront voiceover synthesis and duration sync.
  - Run `npm test`.

## Success Criteria
- [ ] Storyboard generation returns complete storyboard with voiceover WAV already synthesized and attached.
- [ ] Music track and voice model automatically selected to match prompt & tone when set to Auto.
- [ ] Video scene durations mathematically accommodate narration duration.
- [ ] 100% test pass rate.
