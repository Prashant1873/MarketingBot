# Plan 11-01: Kokoro TTS Voiceover Pipeline & Upbeat Music Overhaul

## Objective
Implement local 100% offline Kokoro-82M TTS voiceover generation (`npx hyperframes tts`), overhaul the background music library with upbeat Ende.app Happy Beats tracks, wire voiceover playback with automatic music ducking into the Remotion audio engine, and provide interactive voiceover controls and script editing in the Web GUI.

## Tasks
1. **Upbeat Music Catalog & Render Mapping (`server/data/audioCatalog.js`, `server/services/renderService.js`, `tests/audio.test.js`)**:
   - Update catalog so Ende.app Happy Beats MP3 tracks are default upbeat options.
   - Fix audio file mapping in `renderService.js` to eliminate low-quality scratch WAVs.
   - Update `tests/audio.test.js` to match new catalog defaults.
2. **Kokoro TTS Voiceover Service & Route (`server/services/voiceoverService.js`, `server/routes/voiceover.js`)**:
   - Implement `generateVoiceoverWithKokoro(script, voice)` using `npx hyperframes tts` with Kokoro-82M voices (`af_heart`, `af_nova`, `am_adam`, `bf_emma`, etc.).
   - Implement `POST /api/generate-voiceover` returning `{ voiceoverUrl, durationSec, voice }`.
   - Register route in `server/index.js`.
3. **Remotion Audio Mixer Voiceover & Ducking (`src/remotion/audio/MarcutieAudioMixer.tsx`, `src/remotion/MarcutieComposition.tsx`)**:
   - Add `voiceoverUrl`, `voiceoverVolume`, `voiceoverEnabled` props to `MarcutieAudioMixer.tsx`.
   - Render voiceover `<Audio>` track in Remotion.
   - Apply automatic music ducking (reduce BGM volume to 0.15 during voiceover).
4. **Web GUI Audio & Voiceover Controls (`src/components/AudioControls.tsx`, `src/components/StoryboardInspector.tsx`)**:
   - Add Voiceover toggle, Kokoro voice selector, script editor, and "Generate Voiceover" trigger with live audio preview.
   - Allow previewing upbeat Ende.app tracks.
5. **Verification**:
   - Run test suite and verify end-to-end voiceover generation and audio mixing.
