# Phase 17 Plan: Visual Themes Engine (Apple Light, Neo-Brutalist, Cyberpunk CRT, Aurora Glass)

## Objective
Build a multi-aesthetic visual theme engine supporting 4 design modes (`apple-clean`, `neo-brutalist`, `cyberpunk-scanlines`, `aurora-glass`), dynamically adapting background meshes, typography, card borders, device frames, and procedural overlays across all 4 Remotion scenes.

## Requirements Addressed
- **THEME-02**: Multi-aesthetic visual theme engine (`apple-clean`, `neo-brutalist`, `cyberpunk-scanlines`, `aurora-glass`) adapting shaders, typography, borders, and ambient background styling across all 4 Remotion scenes.

## Vertical Slice Tasks

### Task 1: Theme Architecture & Procedural Shaders
- Extend `ThemePalette` in `src/types/index.ts` with `visualTheme?: VisualTheme` where `VisualTheme = "default-dark" | "apple-clean" | "neo-brutalist" | "cyberpunk-scanlines" | "aurora-glass"`.
- Create `src/remotion/themes/VisualThemeOverlay.tsx`:
  - `cyberpunk-scanlines`: Renders high-tech CRT scanline raster overlay, subtle chromatic aberration edge offset, and phosphor grid glow.
  - `neo-brutalist`: Renders bold solid shadows (`box-shadow: 6px 6px 0px #000`), heavy 3px black borders, and high-contrast color blocks.
  - `aurora-glass`: Ethereal animated multi-color radial gradient mesh simulating the northern lights with frosted specular rim light.
  - `apple-clean`: Crisp pure white/alabaster canvas (`#fbfbfd`), subtle gray borders (`rgba(0,0,0,0.08)`), dark typography (`#1d1d1f`), and refined frosted glass.

### Task 2: Scene Component Adaptations
- Update all 4 scene components (`HookScene`, `ProductRevealScene`, `HighlightScene`, `OutroScene`):
  - Adapt background meshes to respect `visualTheme` (e.g. Light background for `apple-clean`, solid pastel for `neo-brutalist`, CRT for `cyberpunk`).
  - Adapt card borders and text contrast dynamically based on `themePalette.isDark` and `visualTheme`.

### Task 3: Pre-Flight & Storyboard Inspector UI Selectors
- Add Visual Theme selection buttons in `PreFlightStudioPanel.tsx` (Brand & Visuals tab).
- Add Visual Theme quick selector in `StoryboardInspector.tsx` (Brand Style Transfer section).
- Add automated tests in `tests/visualThemes.test.js`.

## Success Criteria
- [ ] Users can select any of the 4 visual themes in PreFlightStudioPanel and StoryboardInspector.
- [ ] Remotion Live Player instantly applies theme shaders, backgrounds, and typography styles.
- [ ] All 4 scenes maintain high readability and WCAG contrast across both light and dark visual themes.
- [ ] Headless MP4 renders bake the chosen visual theme cleanly.
- [ ] Automated tests pass (`npm test`).
