# Phase 18 Plan: High-Quality Animated GIF Export Engine

## Objective
Implement local two-pass FFmpeg animated GIF generation (`palettegen` + `paletteuse`) from rendered MP4 videos, providing instant lightweight GIF loops for READMEs, Product Hunt, and marketing emails.

## Requirements Addressed
- **EXPORT-GIF**: Two-pass FFmpeg animated GIF generator (`palettegen` + `paletteuse`) creating lightweight, crisp 15fps GIF loops with download API and UI buttons.

## Vertical Slice Tasks

### Task 1: Backend Two-Pass FFmpeg GIF Generator Service
- Add `generateGifFromVideo(jobId, options)` to `server/services/renderService.js`:
  - Runs two-pass FFmpeg command:
    - Pass 1: Analyzes video color space and creates optimal 128/256-color palette (`palettegen`).
    - Pass 2: Renders 15fps, 720px width (or responsive aspect scale) animated GIF (`paletteuse=dither=bayer`).
  - Outputs to `data/renders/:jobId/marcutie_preview.gif`.
  - Caches generated GIF to prevent redundant transcoding.

### Task 2: Server API Endpoints
- In `server/routes/render.js`:
  - `POST /api/render/:jobId/gif`: Triggers or returns the generated GIF.
  - `GET /api/render/:jobId/gif`: Streams or downloads `marcutie_preview.gif`.
- Handle error boundaries and missing video states cleanly.

### Task 3: UI Integration in Finished Video Hero & Export Modal
- Update `FinishedVideoHero.tsx`:
  - Add **Download Animated GIF** button with loading spinner state while transcoding.
- Update `ExportModal.tsx`:
  - Add format selector tab: "MP4 Video (1080p)" vs "Animated GIF (Loops/READMEs)".
- Integration tests in `tests/gifExport.test.js`.

## Success Criteria
- [ ] Users can click "Download Animated GIF" and receive a high-contrast, smoothly looping GIF file.
- [ ] GIF file size is optimized for web sharing (< 6MB for typical 15s videos).
- [ ] Two-pass color quantization eliminates color banding artifacts.
- [ ] All tests pass cleanly (`npm test`).
