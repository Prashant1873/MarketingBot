# Phase 12 Plan: Pre-Prompt Customization Studio

## Objective
Overhaul the Studio input interface to provide comprehensive, pre-prompt customization across Theming, Voiceover, Music, and Creative Direction via an interactive Tabbed Studio Panel alongside the Prompt Input, preparing all parameters for one-click video synthesis.

## Requirements Addressed
- **STUDIO-01**: Pre-prompt tabbed customization panel with Brand Theming, Voiceover Studio, Music & Audio, and Creative Direction controls before prompt submission.

## Vertical Slice Tasks

### Task 1: Create `PreFlightStudioPanel.tsx`
- Build a tabbed control surface adhering to `frontend-skill` (dark-mode glassmorphism, crisp badges, smooth pill transitions).
- Tabs:
  1. **Creative & Tone**: Tone preset chips (`default`, `polished`, `yc-parody`, `chaotic`, `deadpan`, `cinematic`, `app-store`), custom direction, aspect ratio buttons (16:9, 9:16, 1:1), duration buttons (15s, 20s, 25s).
  2. **Brand & Theme**: 6 preset palette cards with instant hex pill previews, custom hex pickers for `primary`, `secondary`, `accent`, `background`, and `surface`, Screen Render Mode toggle (`Synthesized HTML/CSS` vs `Direct Screenshot`), and Device Frame override (`Auto`, `macOS Chrome`, `Mobile iPhone`).
  3. **Voiceover Studio**: Voiceover toggle (`Enabled` / `Disabled`), Voice selector dropdown (`AI Auto-Pick [Tone-Matched]`, `af_heart`, `af_nova`, `af_bella`, `af_nicole`, `am_adam`, `am_echo`, `am_eric`, OpenAI voices), Speaking Rate slider (0.85x – 1.3x), and voice audition button.
  4. **Music & Audio**: Upbeat music selector (`AI Smart Select [Prompt-Matched]`, `happy-beats-vol-1`, `vol-10`, `vol-9`, `vol-11`, `vol-12`), Music Volume slider, SFX Volume slider, and Dynamic Ducking depth slider.

### Task 2: Integrate Pre-Flight State into `App.tsx`
- Unify pre-flight state in `App.tsx`:
  - `tone`, `customTone`, `aspectRatio`, `duration`
  - `themePalette`, `screenMode`, `deviceFrame`
  - `voiceConfig` (enabled, voiceId, speed, customNotes)
  - `audioConfig` (track, musicVolume, sfxVolume, duckingDepth)
- Replace sidebar layout with `PreFlightStudioPanel` alongside `PromptInput` and `ImageDropzone`.
- Update sticky footer button to single primary action: **"Generate Finished Launch Video"** (one-click end-to-end), showing recipe summary pills for all selected pre-flight configurations.

### Task 3: Verification
- Verify TypeScript compilation: `npx tsc --noEmit`.
- Verify production build: `npm run build`.
- Verify tests: `npm test`.

## Success Criteria
- [ ] Tabbed Studio Panel displays all 4 tabs with active indicators and responsive layout.
- [ ] Brand colors, voice model, and music track can be customized *before* generating prompt.
- [ ] Primary button is "Generate Finished Launch Video" with clear visual feedback.
- [ ] No regression in existing tests or TypeScript types.
