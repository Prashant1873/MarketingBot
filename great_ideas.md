# Great Ideas

Valuable concepts, design directions, and feature ideas for Marcutie.

## Core Concepts
- **Brag-Grade Launch Videos Without Codebases**: Generating viral, high-converting product launch videos from just a long marketing prompt and/or uploaded product screenshots, mockups, or photos—eliminating the GitHub repo / source code requirement of Hyperframes.
- **Local-First Zero Server Cost Rendering**: Using local Node.js and browser-based Remotion / WebCodecs / Canvas rendering on the user's machine so rendering is 100% free of cloud GPU bills, making the software infinitely scalable and easily hostable.
- **BYOK (Bring Your Own Key) Multimodal Architecture**: Users supply their own Gemini, Claude, or OpenAI API key. This unlocks frontier vision and reasoning without requiring the user to run heavy local vision models or the host to pay subscription API bills.

## Design & Marketing Principles
- **2–3s Hook Law**: The first 2–3 seconds determine whether the viewer stays. The prompt analyzer prioritizes identifying or generating the punchiest visual and textual opening hook.
- **Reading-Time Floor**: High pace is achieved through motion and tight transitions, never by flashing unreadable text. Enforce a minimum hold time (>=0.8s for short text, >=0.3s/word for headlines).
- **Frame-0 Poster Baking**: Social platforms (X, Discord, Slack) generate video preview thumbnails from frame 0. Baking the best settled frame into frame 0 using FFmpeg (`eq(n,0)`) ensures thumbnail previews look intentional and gorgeous.
- **Automatic Multi-Platform Share Copy**: Generating one-click postable captions tailored to the video's tone for Twitter/X, LinkedIn, and Discord alongside the video render.
- **Synthetic Dynamic App Screen Generation (Prompt-Only Mode)**: Programmatically rendering a realistic simulated SaaS/App window (macOS title bar, sidebar navigation, metric widgets, and sparkline graphs) customized to the product domain when no image is uploaded.
- **Image-to-Theme Style Transfer**: Extracting brand color palettes, fonts, and aesthetic styling from uploaded images to theme prompt-generated feature screens so they look like authentic parts of the product.
- **Synthesized HTML/CSS Code Engine with Dual Switch**: Synthesizing real HTML/CSS feature screens rather than just raw screenshots, offering a one-click switch between 'Synthesized HTML/CSS' and 'Direct Screenshot' with a live code inspector.
- **Adaptive Brand Theming & Ambient Mesh Lighting**: Dynamically bathing the entire video background, typography glow, and scene accents in the company's authentic brand palette, ending monochromatic navy blue defaults.
- **Local Kokoro-82M TTS Voiceover & High-Energy Upbeat Audio**: Studio-quality voiceover narration generated 100% locally with Kokoro-82M alongside curated upbeat Ende.app tracks and automatic music ducking.
- **Pre-Prompt Customization Studio**: Deep pre-flight configuration for Brand Theming, Kokoro Voiceover, and Upbeat Music directly in the primary studio interface before prompt submission.
- **One-Click Finished Product Pipeline**: A single primary action that chains storyboard generation, automated voice/music decision, upfront TTS synthesis, and headless Remotion video rendering with frame-0 poster baking, delivering a ready-to-share MP4 immediately without tedious manual post-steps.
- **Kinetic Animated Subtitles & Word-by-Word Voiceover Burn-In**: Dynamic, spring-animated captions (Karaoke Bounce, Clean Frosted Pill, Cyber Glow, Minimal) burned directly into the video to capture the 70%+ of social media viewers watching on mute.
- **Multi-Aesthetic Visual Themes Engine**: Moving beyond single dark mode into four distinct visual design languages (Apple Clean Light mode, Neo-Brutalist solid shadows, Cyberpunk CRT scanline shaders, and Aurora Glassmorphism) with adaptive scene styling.
- **Two-Pass Animated GIF Loops for READMEs**: Local FFmpeg palettegen/paletteuse synthesis generating crisp, lightweight 15fps animated GIFs for Product Hunt discussions, GitHub repository READMEs, and email newsletters where MP4 cannot autoplay.
- **Interactive Director Cockpit & Live Camera Viewport Stage**: A real-time pre-render 3D camera staging viewport featuring live Apple & Mobile device mockups, instant aspect-ratio/duration reframing, 4-act storyboard timeline bar, and one-click launch presets that bridge the gap between creative brief and final render.
- **Physical Fluid Stretch-and-Squish Segmented Rails**: Organic multi-option switches with directional leading/trailing edge delay and mid-flight volume compression (`scaleY(0.92)`), bridging from one option to the next before snapping into place with critically-damped spring mechanics.
